# Interactive workbook content audit

Source: supplied 1437.pdf, 64 pages, first term 2025-2026.

The 64 original scanned pages are retained. Original publication credits remain visible on page 2. The interactive edition attribution is separate.

Every activity page from 4 through 64 is represented. Pages 1-3 remain original front matter. Open-ended writing, discussion, drawings, uncertain speaker attribution and ambiguous source items are not automatically graded. Picture tasks refer back to the preserved original page.

Curated question text has minor spelling, spacing and grammar corrections. This is not a verbatim OCR transcript. Multiple valid choices are accepted where the question permits them.

## Source issues handled

- Page 8: several middle sequence words can form a valid routine; alternatives are accepted.
- Pages 15, 22: OCR omitted a verb or pronoun. The completed prompts were checked against context and the original page.
- Page 20: an awkward school sentence is teacher-reviewed; several transport choices can be valid.
- Page 23: word-form questions also test negative prefixes, following the unit context.
- Page 35: the printed story heading does not match the numbers/sounds exercises; the activity title describes the exercises.
- Page 36: the sentence about Ali and John is missing a linking word, so it is not automatically marked.
- Page 39: swimming in the desert means swimming at the oasis, not in sand.
- Page 43: two source reorder items have verb-agreement errors; they are writing tasks for correction and review.
- Page 45: the source alternates Seleem and Sami for the carpenter. Both are noted rather than silently equated in scored questions.
- Page 48: the printed instruction mentions Siwa/true-false while the questions are about origami/multiple choice; the mismatch is explained.
- Page 53: medal receipt at this story stage and speaker attributions are left for teacher review.
- Page 55: the quiet-girl question is separated from the incorrect front-of-class location.
- Pages 63 and other semantically broad items: more than one grammatically valid answer may be accepted.

## Saving and access

Work is saved in localStorage under the authenticated user ID, separately from existing course progress. It is not cloud-synced. Book notes, original-page annotations and activity responses can be exported/imported as JSON. Existing portal auth, profile, availability controls and course results are unchanged. The card appears inside the authenticated dashboard and respects English-course visibility. Direct workbook navigation checks the existing session and availability; static source assets are not a private file store.

Supabase JS 2.118.0 is vendored with its MIT license. No secret or service-role key is embedded.
