ENGLISH LANGUAGE - PERFORMANCE TASKS AND ASSESSMENT
Primary 4 - First Term
Prepared & Programmed by Mr.Mohamed Farid

The complete supplied 64-page original is preserved alongside interactive activities for every activity page (4-64): six units, weekly quizzes, reviews and model exams.

Included: multiple choice, true/false, missing words, complete passages, word ordering, punctuation, writing tasks, original-page pen/highlighter/text answers, bookmarks, notes, read-aloud instructions where the browser supports speech, and export/restore of a JSON backup.

Closed-answer questions receive immediate feedback with retries. Open writing, discussion, drawing and ambiguous source items are saved for review without automatic marking. See CONTENT-AUDIT.md for content coverage and source corrections.

LOCAL PREVIEW: Open dist/index.html in Edge/Chrome. Keep all files and folders together. Local-file mode uses a separate preview save area.
PORTAL DEPLOYMENT: /interactive-workbook/ in the existing grade4english-portal repository, under gr4.mrfarid.net. The authenticated dashboard has a prominent entry card. The book validates the existing Grade 4 session and respects English-course and login availability settings. The pinned Supabase browser client is bundled locally with its license.

SAVING: Work is saved in this browser on this device, separated by authenticated user ID. It is NOT cloud-synced and does not alter the existing course_progress records. Export a backup before changing devices or clearing browser data. Restore work from the Home page imports that backup.

ORIGINAL: original-book.pdf is an unmodified copy of the supplied 1437.pdf. Original authorship and publisher credits remain in the original pages. The interactive software attribution is separate.

AUTHORING: edit data/workbook.json and run python build-data.py to rebuild workbook-data.js. No package installation or framework build is required.
